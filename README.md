# 狐兔 · 齿轮沙漠星 / Foxbun: Gear Desert

A small canvas platformer for GitHub Game Off 2026, themed **SHIFT**. Explore the desert, collect coins, and reach the glowing save point.

Switch between Gear 1 and Gear 2 to move the gear platforms and open the opposing shutters. Gear 1 powers the updraft; Gear 2 stops it and raises the platforms into a staircase. Switch back to Gear 1 to pass the final shutter. Coins reward exploring both configurations.

## Play

Open `index.html` in a browser, or run `python3 -m http.server` in this directory and visit the local server. No external libraries or network connection are required.

- Move: Left/Right arrows or A/D
- Jump: Space, Up, W, or Z; hold jump in the air to glide and ride the updraft
- Shift gears: either Shift key, X, or K
- Touch: use the on-screen movement, jump, and 换挡 buttons
